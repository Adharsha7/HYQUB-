Generate ML-DSA-65 Keypair
GET /dev/generate-keypair
DEV ONLY
This calls /dev/generate-keypair, a development-only endpoint that generates an ML-DSA-65 keypair on the backend and returns the secret key to the browser. This endpoint is only registered when the server is running in development mode.

In production, a user's ML-DSA secret key must never leave their device. This shortcut exists because no browser-side ML-DSA WASM library is integrated yet.
Only available when HYQUB_ENVIRONMENT=development

Rotate Key
POST /rotate — increments key_version; re-run Steps 1 → 4 after rotation
After rotation, key_version increments. Any signature created with the old key will be rejected. You must regenerate a keypair (Step 1), then re-run Step 4 to get a new message_hash with the updated key_version, then re-sign (Step 5).
